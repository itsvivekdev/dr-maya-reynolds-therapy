## 📌 About The Project
This is a landing page built for a private therapy practice. The main idea was to create a calm, clean, and distraction-free design that helps potential clients easily learn about therapy services and book an appointment.

### What’s inside:
- **Mobile-first design:** Fully responsive layout with a slide-out drawer menu on mobile screens and clean navigation on desktop.
- **Server & Client Components:** Kept all static content (about, services, office details) as Server Components for fast loading, while keeping only interactive elements (like the navigation drawer) as Client Components.
- **Typography & Theme:** Custom typography using Cormorant Garamond for headings and Mulish for readable body text, paired with a soft, calming color palette.
- **Sections included:** Hero, About, Focus Areas, Treatment Methods (CBT, EMDR, Somatics), Santa Monica Office details, and Booking CTA.
